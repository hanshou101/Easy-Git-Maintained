## 1. 本目录是什么

不依赖 Obsidian 实例即可运行的回归验证脚本。它们用 esbuild 打包目标 TypeScript 与必要 stub，在 Node 中检查最容易被平台和字节差异破坏的同步路径。

## 2. 直属文件

- `crlf-regression.mjs`：覆盖 CRLF/LF、UTF-8 BOM、wikilink、callout/高亮/math push-pull 变换和 base64 往返，确保转换不污染字节格式。
- `hidden-path-regression.mjs`：用内存 adapter 验证 dotfile/dot-directory 扫描、`.gitignore` 字节保留、隐藏目录安全排除以及 workflow 权限错误提示。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 两个脚本分别由 `npm run test:crlf` 和 `npm run test:hidden` 调用，断言失败必须以非零状态退出。
- stub 只替代 Obsidian 运行环境，不应复制一份待测算法；待测实现仍从 `src/` 打包进入脚本。
- 修改换行、隐藏路径、Markdown 变换或 workflow 权限错误时，应同步扩充对应回归脚本。

## 5. 什么时候需要下钻

- 排查平台换行/BOM 问题读 `crlf-regression.mjs`；排查隐藏文件或 adapter 行为读 `hidden-path-regression.mjs`。
