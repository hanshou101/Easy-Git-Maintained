# .frac.md — scripts

> 生成规则：本文件只总结当前目录的直属文件，以及直属子目录的 `.frac.md`。
> 输入范围：direct-files + child-fracs only

## 1. 本目录是什么

不依赖 Obsidian 实例即可运行的回归验证脚本，检查最容易被平台和字节差异破坏的同步路径。每个脚本用 Vite（SSR、内存输出）把一段虚拟 `.ts` 测试入口连同 `./src/...`（相对仓库根解析）打包；需要 `obsidian` 的由 `resolveId`/`load` 插件换成桩模块；打出的 ESM 以 data URL 在 Node 中执行。

## 2. 直属文件

- `crlf-regression.mjs`：换行策略回归——push 与 pull 两侧的换行转换、第二次同步 noop、UTF-8 BOM、二进制绕过、三方合并，以及 wikilink/callout/高亮/math 往返；确保仓库与工作区表示不会反复翻转。
- `hidden-path-regression.mjs`：内存 adapter 验证 dotfile/dot-directory 扫描、隐藏路径采用同一 push 规范 SHA、`.easygitignore`/安全排除、备份删除以及 workflow 权限错误提示。
- `submodule-regression.mjs`：内存 adapter 验证本地扫描只排除 `.gitmodules` 声明的子仓目录及其孙仓、`.git` 内部文件；仓库自身文件、未声明的嵌套仓和直接被映射的子仓自己的文件照常同步（整库、仓库根、子仓根映射都覆盖）。
- `upstream-plugin-regression.mjs`：打包真实的 `src/main.ts` 与 `src/upstream-plugin.ts`，`obsidian` 换成能构造插件的桩；验证上游 `easy-git` 启用且已安装时 `onload()` 只弹通知、不注册命令、不写 data.json（残留的启用记录不算）；首次启动接手上游 data.json（含同步状态与 token），之后只读自己的，自己的读坏时不接手。

## 3. 子目录导航

无直属子目录。

## 4. 本层约束 / 约定 / 禁忌

- 各脚本由 `package.json` 的 `test:crlf`、`test:hidden`、`test:submodule`、`test:upstream` 调用，断言失败必须以非零状态退出。
- stub 只替代 Obsidian 运行环境，不复制待测算法；待测实现仍从 `src/` 打包进入脚本。
- 模板字符串里的测试源码与 stub 就是断言本身，换打包方式只改文件头和末尾的打包段；解析不到的导入（包括没有 stub 的 `obsidian`）必须让打包直接失败，不能被悄悄外置。
- 改换行策略时必须同时证明“扫描 SHA = 实际上传字节”和 pull 写盘格式；隐藏路径、Markdown 变换或 workflow 权限错误有变化，也要扩充对应脚本。

## 5. 什么时候需要下钻

- 平台换行/BOM 问题读 `crlf-regression.mjs`；隐藏文件或 adapter 行为读 `hidden-path-regression.mjs`；子仓/嵌套仓被误排除或漏排除读 `submodule-regression.mjs`；与上游插件并存、换装后设置没接上读 `upstream-plugin-regression.mjs`。
