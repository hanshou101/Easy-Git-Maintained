## 1. 本目录是什么

Easy Git 插件源码总入口。直属文件管理 Obsidian 生命周期、持久化设置和共享数据契约；远端访问、同步算法和交互组件分别下沉到三个子目录。

## 2. 直属文件

- `main.ts`：插件生命周期与应用编排；上游 Easy Git（`easy-git`）在本 vault 已安装并启用时，`onload()` 弹一条不消失的通知后直接返回，什么都不注册；没有自己的 data.json 的首次启动，`loadSettings()` 接手上游的 data.json（mapping 连同同步状态、认证、排除等）并另存为自己的、弹通知（自己的 data.json 读坏时不接手）；注册 ribbon/commands/status bar，维护 interval/startup/on-save 触发、同 mapping 串行化和 pending 重跑，归一化旧 mapping 的换行策略，调用 `SyncEngine` 并记录结果。
- `settings.ts`：折叠式设置页；管理 provider/凭据、folder mappings、冲突与备份策略、同步行为、排除路径、通知、诊断和 About（显示 manifest 的名字与版本，链接指向本维护仓并附上游链接），并对可见 mapping 行做局部状态刷新。
- `secret-storage.ts`：优先经 Obsidian `app.secretStorage` 读写 token（secret id `easy-git-token`，与上游相同，换装后不用重新登录，不要改）；旧版本无该 API 时允许 settings fallback，并提供能力检测和清除操作。
- `upstream-plugin.ts`：上游插件 id `UPSTREAM_PLUGIN_ID = "easy-git"`；`upstreamPluginEnabled()` 只在上游 id 既在已启用列表、又确实装着（`app.plugins.manifests` 里有）时为真，旧目录被本版覆盖后残留的启用记录不算；`readUpstreamSettings()` 从上游插件的实际目录（手动安装的目录名可能不是 id，找不到再退回 `<configDir>/plugins/easy-git`）读 data.json，读不到或不是对象就返回 null。本版 id 等于上游 id 时两者都不生效。
- `types.ts`：mapping、destination、认证、last-known state、同步日志、冲突、文件动作和结果的共享类型；定义 push `preserve|lf`、pull `preserve|crlf`、默认设置、provider base URL 校验与对象 ID/初始 mapping 工厂。

## 3. 子目录导航

- `github/`：见 `github/.frac.md`；认证、HTTP client 与 Git 数据/provider 适配。
- `sync/`：见 `sync/.frac.md`；扫描、分类、变换、冲突、备份和提交的同步核心。
- `ui/`：见 `ui/.frac.md`；mapping、认证、冲突、诊断、日志和状态反馈组件。

## 4. 本层约束 / 约定 / 禁忌

- 插件 id 是 `easy-git-maintained`，不能改回 `easy-git`；命令 id 随之是 `easy-git-maintained:*`。与上游同时启用会两边同步同一批文件夹，所以上游启用时本版不运行。
- `main.ts` 保存设置时必须把 token 从普通 `data.json` 分离到 secret storage；引擎回调走 `saveSettings()`，不能直接 `saveData()` 泄露凭据。
- 同一 mapping 同时只能有一个同步在飞；触发重叠时记录一次 pending，并在当前运行结束后重跑。
- provider 配置在认证层选择，mapping 与同步结果保持 provider 无关的共享形状；换行策略属于 mapping，缺失值必须按 `preserve` 向后兼容。
- Obsidian 依赖应停留在编排/UI/adapter 边界；可纯测的分类、编码和变换逻辑继续放在 `sync/` 小模块。

## 5. 什么时候需要下钻

- 改命令、自动触发、设置迁移或结果日志时读直属 `main.ts`/`settings.ts`/`types.ts`；改与上游插件的关系（启用检测、接手设置）读 `upstream-plugin.ts` 和 `scripts/upstream-plugin-regression.mjs`。
- 改网络/provider 时读 `github/.frac.md`；改同步语义时读 `sync/.frac.md`；改界面时读 `ui/.frac.md`。
